# claude-code-session-playback (ccplayback)

Claude Code とのセッション(`*.jsonl`)を選んで、ブラウザ上でチャットログとして
「プレイバック」できるデモ用ツールです。チームメンバーに使い方をデモする用途を
想定しています。

## 使い方

```sh
ccplayback                      # カレントディレクトリのプロジェクトのセッション
ccplayback ~/myproject          # 指定したプロジェクトのセッション
ccplayback ~/.claude/projects   # 全プロジェクトのセッションを横断
```

`npm link` などせずに直接実行する場合は `node bin/ccplayback.js [ディレクトリ]`。

1. 対象のセッションを新しい順に最大10件、一覧表示します。
   一覧には最終更新の相対時刻・往復数・ツール実行回数・所要時間・
   最初のプロンプトの抜粋が出ます(そのまま Enter で最新のセッションを選択)。
2. 番号を選ぶと、そのセッションを解析してローカルサーバーを起動し、
   ブラウザ(Chromium系があれば優先して起動)で再生画面を開きます。
3. 「進む」ボタン(または → / Space キー)でユーザーの発言・Claudeの思考・
   応答テキスト・ツール呼び出しを1つずつ、タイプライター風に表示していきます。
   「戻る」(← キー)で1つ前に戻れます。タイピング中に「進む」を押すか
   画面をクリックすると、即座に全文表示にスキップできます。

## セッションの jsonl はどこにある?

Claude Code のトランスクリプトはプロジェクトの中ではなく、設定ディレクトリ配下に
保存されます。

```
~/.claude/projects/<プロジェクトのパスをスラッグ化した名前>/<セッションID>.jsonl
```

- スラッグは作業ディレクトリの英数字以外をハイフンに置き換えたもの
  (例: `/home/user/my.project` → `-home-user-my-project`)
- `~/.claude` は環境変数 `CLAUDE_CONFIG_DIR` で変更できます
- サブエージェントの記録は `<セッションID>/subagents/agent-*.jsonl` にありますが、
  単体では会話として成立しないため一覧には出しません

そのため `ccplayback ~/myproject` のようにプロジェクトのディレクトリを渡すと、
対応する `~/.claude/projects/...` を自動で解決して一覧表示します。
トランスクリプトのディレクトリを直接渡しても動きます。

## 画面の操作

| 操作 | 内容 |
| --- | --- |
| 進む / → / Space | 次のステップを表示(タイプ中は全文表示にスキップ) |
| 戻る / ← | 1ステップ戻る |
| x1 / x2 / 即表示 | タイプライターの速度切り替え |
| ↺ 最初から | 表示をリセット |
| もっと見る | 長いツール入力・実行結果を全文表示 |

`?start=8` のようにクエリを付けて開くと、そのステップまで表示済みの状態で
始められます(デモの途中再開用)。

## 特徴

- 依存パッケージなし(Node.js 標準ライブラリのみ)
- ユーザー発言 / Claude の応答テキスト / thinking / ツール呼び出し+結果を
  それぞれ見た目を変えて表示
- 1文字ずつ揺らぎのある速度で表示する「プレイバック」演出
- 長い実行結果は高さを抑えて折りたたみ、必要なときだけ全文表示
- 再生するのは人の発言と Claude の応答のみ。バックグラウンドタスクの通知や
  自動再開のメッセージなど、システムが会話に差し込んだ記録は表示・集計から除外
